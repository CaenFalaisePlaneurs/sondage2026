# Sondage Club 2026 — Caen Falaise Planeurs

À l’été 2026, le Caen Falaise Planeurs a interrogé ses membres sur leur place dans le club. Le questionnaire a été mis en ligne le 2 août 2026. Les 33 réponses réunies ici ont été enregistrées du 3 août au 4 octobre 2026.

Les questions portaient sur le profil et la fréquentation, la satisfaction, le sentiment d’appartenance, l’ambiance, la liberté de proposer une idée, la communication, la gouvernance et l’envie de s’impliquer davantage. Cette synthèse est anonyme : les réponses libres ont été reformulées, et aucune phrase d’origine n’est reproduite.

Les réponses d’origine sont dans le tableur [Réponses sondage club 2026](https://docs.google.com/spreadsheets/d/1JPMS161n52ntVELLhkCbfIIjuhwpahuzni94DoXdqZA/). Ce fichier n’est pas anonymisé. Le site et le PDF `sondage-club-2026.pdf` n’en reprennent que la synthèse.
